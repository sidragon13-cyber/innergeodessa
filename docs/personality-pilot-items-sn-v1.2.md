## 4. Scoring key

Response coding:

| Disagree | 2 |
| Neither agree nor disagree | 3 |
| Agree | 4 |
| Strongly agree | 5 |

SN directional scoring:

- S-keyed item: `S contribution = raw value`; `N contribution = 6 - raw value`.
- N-keyed item: `N contribution = raw value`; `S contribution = 6 - raw value`.
- Equivalent signed score: S-keyed items use `raw - 3`; N-keyed items use `3 - raw`.
- Positive signed totals indicate an S tendency; negative totals indicate an N tendency; values near zero indicate weak differentiation.

## 9. Post-pilot analysis specification

| Analysis | Review purpose | Initial flag criterion |
| --- | --- | --- |
| Missing response rate | Accessibility or wording problem | `>5%` |
| Category distribution | Unused response options | Any category `<5%`, interpreted with sample size |
| Extreme endorsement | Floor or ceiling concentration | Responses 1+2 or 4+5 `>80%` |
| Corrected item–total correlation | SN discrimination | `<0.20` serious review; `0.20–0.29` caution |
| Within-subdimension correlation | Local consistency | Negative or near-zero correlation |
| Inter-item correlation | Redundancy | `>0.70` review for duplication |
| Alpha or omega if item deleted | Reliability contribution | Never use as sole deletion rule |
| S/N directional pattern | Keying and construct check | Item moves opposite to coherent pattern |
| Differential item functioning | Language, region or demographic bias | Material effect after matching on trait level |
| Cognitive feedback | Misinterpretation or ambiguity | Repeated common misreading |
| Response time | Reading burden | Repeated extreme delay relative to form median |
