## 9. Freeze Rules

After this freeze:

1. K912 Helpful visual content must not be casually regenerated.
2. Existing mappings must not be changed without opening a new
   controlled revision.
3. PNG Master assets must not be destructively recompressed.
4. Frontend production should use the frozen WebP assets.
5. Any future replacement requires:
   - documented reason
   - new version
   - visual review
   - updated SHA inventory
   - new freeze revision
6. Backup and staging directories are not production assets and are
   excluded from this freeze.
