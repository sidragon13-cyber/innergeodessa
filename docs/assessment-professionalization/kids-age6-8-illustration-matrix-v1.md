## 1. Purpose

This matrix determines whether each candidate item requires an illustration, benefits from an illustration, or can remain text-sufficient.

Classification:

- **Required** — visual support is necessary for comprehension or construct clarity.
- **Helpful** — visual support may improve comprehension but must be reviewed for bias.
- **Text-Sufficient** — wording is simple enough that adding an image may create more bias than benefit.

## 4. Review Rule

This classification is a planning aid, not final illustration approval.

Before implementation:

- Required items must receive illustration review.
- Helpful items may be downgraded to text-only if visual bias risk exceeds comprehension benefit.
- Text-Sufficient items should remain text-first unless pilot evidence shows comprehension problems.
- No illustration is approved solely because it improves appearance.
