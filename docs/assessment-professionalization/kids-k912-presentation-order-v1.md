## 1. Purpose

This document freezes the presentation order used by the production K912 assessment.

## 2. Interleaving Rule

The 40 selected items are presented as five rounds.

Each round contains one item from each of the eight Kids interest domains.

The starting domain advances by one canonical domain position per round.

Within each domain, the Release Form selected-item order is preserved.
