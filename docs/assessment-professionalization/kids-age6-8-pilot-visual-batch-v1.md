# InnerGeo Kids — Ages 6–8 Pilot Visual Batch V1.0

**Status:** Pilot Image Generation Plan
**Pilot Images:** 3
**Production Approved:** No

---

## 1. Purpose

The first image-generation batch intentionally contains only three illustrations.

The objective is to validate:

- master visual style;
- age appropriateness;
- composition consistency;
- construct clarity;
- visual attractiveness balance;
- ability-contamination control;
- accessibility representation.

The remaining Required illustrations should not be generated until this pilot batch passes review.

---

## 2. Pilot Item 1

### K68-CREATE-01 — Original Visual Expression

**Reason selected:**

Tests whether the master art style can represent creativity without visually reducing Create to conventional drawing ability.

**Core scene:**

A child aged approximately 6–8 shapes an original visual idea using several simple methods such as arranging large shapes, selecting forms, moving visual elements, or drawing.

**Must communicate:**

- imagination;
- choice;
- shaping an original idea;
- accessible creative participation.

**Must not communicate:**

- artistic talent;
- professional drawing;
- expensive materials;
- polished final artwork;
- adult approval;
- competition.

**Pilot review priority:**

Style consistency and creative-accessibility neutrality.

---

## 3. Pilot Item 2

### K68-THINK-02 — Sequencing Interest

**Reason selected:**

This is the strongest test of the boundary between an interest illustration and an ability test.

**Core scene:**

A child aged approximately 6–8 is arranging a simple sequence of large objects or symbols.

The activity is visibly in progress.

The viewer is not presented with a missing-answer puzzle.

**Must communicate:**

- sequencing as an activity;
- curiosity;
- arranging relationships;
- engagement with order and sequence.

**Must not communicate:**

- solve this puzzle;
- correct answer;
- IQ test;
- school examination;
- time pressure;
- performance comparison.

**Pilot review priority:**

Ability-contamination control.

---

## 4. Pilot Item 3

### K68-MOVE-02 — Movement-Based Exploration

**Reason selected:**

Tests whether accessibility can be represented naturally without making disability itself the subject of the illustration.

**Core scene:**

Several children aged approximately 6–8 explore a simple route or set of activity stations using different valid forms of movement.

**Must communicate:**

- active exploration;
- movement;
- equal participation;
- multiple valid ways of moving.

**Must not communicate:**

- racing;
- winning;
- athletic superiority;
- speed;
- pity;
- inspirational-disability framing;
- separate treatment.

**Pilot review priority:**

Accessibility and equal-participation representation.

---

## 5. Shared Production Controls

All three pilot images must use:

- 4:3 landscape composition;
- same master illustration style;
- comparable character scale;
- comparable colour saturation;
- comparable background complexity;
- soft even lighting;
- neutral-positive expressions;
- simple everyday environments;
- no text inside image;
- no logos;
- no brands;
- no trophies;
- no reward effects;
- no cinematic lighting;
- no luxury cues.
