# InnerGeo Professional Report Standard V1.1

**Edition:** Compact Professional Edition
**Status:** Gate 17 Professional Report Foundation
**Scope:** Personality / Career / Kids Interest Discovery / Zodiac
**Relationship:** Extends `InnerGeo Professional Assessment Standard V1.0`
**Purpose:** Define the unified professional standard for InnerGeo free results and premium reports.

---

# 1. Core Report Principle

InnerGeo reports must maximize:

1. Professional credibility
2. Evidence quality
3. Interpretive clarity
4. Individual differentiation
5. Data transparency
6. Practical usefulness
7. Ethical boundaries
8. Information density

The objective is not to generate the longest report.

The objective is to generate the most useful report that can be justified by the available evidence.

> Professional value comes from judgment quality, evidence, personalization, context, and actionability — not page count.

---

# 2. Product Position

InnerGeo is not a collection of isolated tests.

The reporting system should create one coherent user experience:

Assessment
↓
Scoring / Calculation
↓
Interpretation
↓
Data Context
↓
Personal Position
↓
Relevant Future Context
↓
Opportunity / Exploration
↓
Action

The user should leave the report understanding:

- what the assessment found;
- how strong or differentiated the pattern is;
- what the result does and does not mean;
- where the pattern may matter in real life;
- what external data or research provides useful context;
- how changing technology or environments may affect relevant choices;
- what to explore or build next.

---

# 3. Assessment Core and Context Intelligence Must Remain Separate

InnerGeo uses two fundamentally different information layers.

## 3.1 Assessment Core

Stable, versioned assessment information.

Examples:

- Personality dimensions
- Personality type
- RIASEC scores
- Kids eight-domain scores
- Kids pattern type
- Zodiac calculated chart facts

Assessment Core owns:

- scores;
- rankings;
- ties;
- clusters;
- pattern classification;
- calculated chart positions;
- scoring-derived signals.

The report layer must not recalculate these facts.

## 3.2 Context Intelligence

Externally sourced information used to explain the changing world around the user.

Examples:

- employment trends;
- occupational outlook;
- AI adoption;
- automation exposure;
- robotics;
- digital economy;
- creative technology;
- education pathways;
- industry change.

Context Intelligence may be updated independently.

It must never silently change the underlying assessment result.

# 4. Five Evidence Levels

Every important report statement should conceptually belong to one of five evidence levels.

## Level A — Assessment Fact

Directly generated by the assessment or calculation system.

Examples:

- INTJ
- Investigative = 82
- Broad Explorer
- highlightedDomains = [...]
- Sun in Virgo

These are facts about the assessment result, not facts about the user's entire identity.

## Level B — Interpretation

A structured interpretation based on Level A.

Examples:

- a relatively stronger preference for independent analysis;
- a blended interest pattern;
- current curiosity distributed across several activity domains.

Interpretation must use calibrated language.

## Level C — Research / Benchmark Context

External evidence used to provide comparison or context.

Examples:

- reference population prevalence;
- occupational research;
- research on person-environment fit;
- labour-force statistics.

Every material quantitative claim must have a source.

## Level D — Future / Market Context

Dynamic external information.

Examples:

- AI task transformation;
- automation adoption;
- industry growth;
- technology trends;
- future skill demand.

These claims must include a verification date and must not be embedded inside scoring algorithms.

## Level E — Recommendation

An actionable suggestion built from Levels A–D.

Recommendations must remain exploratory rather than deterministic.

Preferred framing:

- worth exploring;
- consider testing;
- may be useful to develop;
- compare against real-world evidence;
- observe whether this pattern persists.

---

# 5. Evidence Chain

Important conclusions should preserve a visible reasoning structure:

Assessment Fact
↓
Interpretation
↓
External Context where relevant
↓
Practical Meaning
↓
Recommendation

Reports must avoid:

Answer
↓
Major life conclusion

without an explainable intermediate evidence chain.

# 6. Free Result Standard

Free results must provide genuine professional value.

They must not be intentionally weakened to force payment.

Recommended length:

- approximately 3–4 screen-equivalent pages;
- concise enough for mobile reading;
- sufficient to establish result credibility.

A Free Result should normally contain:

## 01 Core Result

The primary assessment result.

## 02 Result Interpretation

What the result means in plain language.

## 03 Profile Structure

Important score structure, dimensions, pattern, or combination.

## 04 Key Signals

Only signals supported by scoring or calculation.

## 05 Data / Method Context

A small amount of meaningful methodological or benchmark context where appropriate.

## 06 Practical Meaning

How the pattern may appear in work, learning, activities, reflection, or everyday decisions.

## 07 Simple Guidance

A small number of useful next steps.

## 08 Premium Preview

Clearly explain what additional decision value the Premium Report provides.

Free Result value:

> Prove credibility.

Premium Report value:

> Improve decisions.

---

# 7. Premium Report Size Standard

InnerGeo uses a Compact Professional Report model.

## Target

Most Premium Reports:

**10–14 pages**

## Soft Maximum

Normally:

**16 pages**

The report must not expand simply to reach a page count.

Page count is a product-design guide, not a content quota.

## Language

English and Chinese are separate localized report outputs.

Do not duplicate both languages side-by-side inside the same user report unless specifically requested.

---

# 8. Premium Report Unified Architecture

Premium Reports use eight primary modules.

Module names may be localized or adapted by assessment type, but their information responsibilities should remain clear.

---

## 01 Executive Profile

Purpose:

Give the user the highest-value interpretation first.

Include:

- core result;
- current profile pattern;
- 3–5 most important findings;
- important uncertainty or balance information;
- concise practical takeaway.

Avoid:

- generic motivational introduction;
- repeating later sections in full.

---

## 02 Profile Structure & Interpretation

Purpose:

Explain how the result is structured.

Possible content:

- dimensions;
- rankings;
- score gaps;
- confidence;
- combinations;
- ties;
- pattern type;
- profile interaction.

This section answers:

> What exactly produced this result?

---

## 03 Personal Position & Data Context

Purpose:

Place the result into useful context without creating false precision.

Possible content:

- reference distributions;
- population or sample comparisons;
- benchmark data;
- relevant research;
- methodological limitations.

Every statistic must provide sufficient metadata.

Never imply:

Rarity = superiority.

---

## 04 Strengths, Environment & Blind Spots

Purpose:

Integrate several previously repetitive topics into one high-density section.

Possible content:

- environments in which the pattern may work well;
- likely modes of engagement;
- learning or work preferences;
- collaboration patterns;
- common trade-offs;
- possible blind spots;
- situations in which strengths may become overused.

Do not repeat the same trait description in multiple subsections.

---

## 05 Career / Learning / Life Environment Fit

Purpose:

Translate the profile into relevant real-world environments.

Content varies by assessment.

Personality may include:

- work environment;
- learning style;
- collaboration context;
- decision environment.

Career may include:

- person-environment fit;
- occupational families;
- role exploration;
- task profiles.

Kids may include:

- activity environments;
- learning exploration;
- home exploration;
- social / creative / technical contexts.

Zodiac must keep this section reflective and symbolic, not scientific career prediction.

---

## 06 Future Context

Purpose:

Explain only future trends materially relevant to the user's result.

Possible domains:

- AI
- automation
- robotics
- cybersecurity
- data
- digital economy
- gaming
- creative technology
- AR / VR
- green economy
- biotechnology
- future of work

Do not include every topic in every report.

Normally choose only:

**2–4 highly relevant contexts**

The report should answer:

- What is changing?
- Why is it relevant to this profile?
- Which tasks or environments may change?
- Which human capabilities may remain valuable?
- What uncertainty remains?

Future Context must never modify Assessment Core scoring.

---

## 07 Opportunity & Skills Map

Purpose:

Convert interpretation and context into development priorities.

Possible content:

- areas worth exploring;
- skills worth strengthening;
- portfolio or project evidence;
- practical experiments;
- learning priorities;
- decision criteria.

Recommendations should be specific enough to act on but flexible enough to validate in real life.

---

## 08 Personal Future Map

Purpose:

End the report with a practical sequence.

Default framework:

### Now

What to understand or verify immediately.

### 0–6 Months

Short experiments, exploration, foundational skills, observation.

### 6–12 Months

Deeper development, portfolio evidence, education, experience, or structured decisions.

### 12–36 Months

Strategic direction rather than deterministic prediction.

The plan must be derived from the report.

It must not be generic self-improvement filler.

---

# 9. Appendix Standard

The following should normally be compact and placed at the end.

## Methodology

Explain:

- assessment construct;
- scoring/calculation version;
- interpretation scope;
- important limitations.

## Sources

List material external evidence used.

## Boundaries

Explain what the assessment cannot establish.

Appendices should provide credibility without unnecessarily increasing report length.

11. Source Quality Hierarchy

Preferred sources:

Tier 1
Government statistical agencies
OECD
World Bank
ILO
UN agencies
official professional bodies
peer-reviewed research
Tier 2
recognised academic institutions
official industry associations
IFR and equivalent specialist bodies
official company research where directly relevant
Tier 3
credible specialist industry research

Tier 3 sources require greater care in wording and limitations.

Avoid using low-quality secondary articles as the primary source of major professional claims.

12. Citation Standard

Premium reports must support traceable evidence.

For important external claims retain:

source;
year;
study or dataset;
population/sample where relevant;
link or citation;
last verified date.

Avoid:

Research shows...

without identifying the research basis.

A report does not need a citation after every sentence.

Citations should support material claims where external evidence affects interpretation or recommendations.

13. Data Freshness

Dynamic data must have a verification date.

Examples:

AI adoption;
employment growth;
salary;
occupational demand;
technology market size;
automation trends.

Dynamic context must use a version such as:

FUTURE-CONTEXT-2026-H2

Future examples:

FUTURE-CONTEXT-2027-H1

Updating Future Context must not silently change historic Assessment Core results.

14. Anti-Repetition Standard

The same finding should normally be explained once.

Bad structure:

Profile description
↓
Strength section repeats description
↓
Work section repeats description
↓
Career section repeats description
↓
AI section repeats description

Preferred structure:

Finding
↓
Meaning
↓
Environment effect
↓
Future implication
↓
Action

Each later section should add new decision value.

15. Information Density Standard

Every section should answer a distinct user question.

Before adding a paragraph, ask:

Does this add new evidence?
Does this improve interpretation?
Does this improve personalization?
Does this improve a decision?
Does this explain uncertainty or limitations?

If the answer is no to all five, the paragraph is probably unnecessary.

16. Personalization Standard

Premium reports must not be simple type templates.

Where available, personalization should use:

dimension strength;
rankings;
score gaps;
ties;
combinations;
pattern structure;
confidence;
dynamic interpretation rules;
age group;
user-supplied goals;
relevant contextual information.

Reports should distinguish between:

same type

and

same exact profile structure.

Two users with the same top-level type should not automatically receive identical interpretation.

17. Language Calibration

Avoid deterministic language.

Do not use:

you will;
you cannot;
you are destined to;
you are naturally superior;
this proves;
this guarantees;
you must choose;
this is your perfect career.

Prefer:

tends to;
may prefer;
currently shows;
may be more comfortable with;
can become more noticeable when;
worth exploring;
one possible interpretation;
may fit better with;
compare this with real-world evidence.

Chinese equivalents should preserve the same degree of certainty.

18. Personality Report Specialization

Personality reports should prioritize:

dimension structure;
score strength;
confidence / closeness;
integrated type pattern;
environment fit;
work and learning style;
collaboration;
trade-offs;
relevant future-of-work implications;
personal development.

Avoid stereotype-heavy type descriptions.

Personality reports must not claim clinical psychological diagnosis.

19. Career / RIASEC Report Specialization

Career reports should prioritize:

complete RIASEC profile;
top-code structure;
score gaps;
combinations;
Person–Environment Fit;
occupational families;
task environment;
role exploration;
current labour-market context;
AI / automation task context;
skills;
exploration plan.

Interest must remain distinct from:

ability;
employability;
qualification;
job performance;
guaranteed income;
guaranteed career success.

Career suggestions are exploration candidates, not prescriptions.

Kids remains:

Interest Discovery

Never:

Talent Test
Ability Ranking

Career Prediction

Kids reports should prioritize:

current Interest Pattern;
eight-domain Interest Map;
highlighted signals only when scoring allows;
combinations;
broad / emerging patterns;
exploration activities;
parent observation;
learning environment;
home exploration;
persistence observation;
Discover → Explore → Cultivate.

Never describe a child as:

weak;
bad at;
low ability;
not talented;
unsuitable;

For Broad Explorer:

do not force Top 1 / Top 2 / Top 3;
encourage broad exposure before narrowing.
21. Zodiac Report Specialization

Zodiac belongs to:

Reflective / Cultural Content

It is not:

Psychometric Assessment

Reports must clearly preserve this distinction.

Zodiac may include:

calculated chart structure;
symbolism;
cultural / historical framing;
reflection prompts;
relationship themes;
life reflection;
practical experiments.

Zodiac must not be presented as scientific evidence for:

personality diagnosis;
mental health;
career suitability;
compatibility certainty;
future events;
medical outcomes.

Where career or life themes are mentioned, they must remain reflective prompts.

22. Free vs Premium Boundary

Free Result:

proves assessment value;
explains the result clearly;
provides useful basic guidance.

Premium Report:

provides deeper interpretation;
stronger differentiation;
external context;
data;
research evidence;
relevant future context;
opportunity mapping;
structured action.

Premium is not:

Free Result + more paragraphs.

23. Report Versioning

Every report product should retain appropriate version metadata.

Recommended:

reportVersion
contentVersion
ruleVersion
assessmentVersion
contextVersion
generatedAt
lastContextVerified

Historic generated reports should retain the versions used when they were generated.

Updates should not silently rewrite the meaning of earlier reports.

24. Bilingual Standard

English and Chinese reports must preserve:

the same construct;
the same certainty level;
the same evidence;
the same limitations;
the same conclusions;
equivalent actionability.

Translation may adapt natural phrasing.

Translation must not change professional meaning.

25. Visual Report Principle

Report visual design should support comprehension.

Prioritize:

clear hierarchy;
charts where they improve understanding;
data cards;
concise comparison blocks;
source markers;
readable spacing;
mobile readability;
printable structure.

Avoid decorative complexity that reduces information clarity.

26. Commercial Quality Test

Before a Premium Report is commercially released, ask:

Is the result genuinely individualized?
Is each major conclusion traceable?
Are important external statistics sourced?
Is dynamic information current?
Are uncertainty and limitations visible?
Does each section add new value?
Is the report concise enough to finish?
Does the user know what to do next?
Is the report meaningfully better than the free result?
Would a knowledgeable reader consider the report professionally defensible?

If several answers are no, the report is not commercially ready.

28. Final Professional Principle

InnerGeo does not decide who the user is.

It provides structured evidence about a result.

InnerGeo does not predict a fixed future.

It helps users understand relevant possibilities.

InnerGeo does not replace real-world evidence.

It helps users decide what evidence to gather next.

The professional report should therefore move from:

Assessment → Interpretation → Evidence → Context → Action

with every transition remaining explainable.
