# InnerGeo Kids — Ages 6–8 Candidate Item Pool V1.0

**Status:** Candidate Pool — Not Production Ready  
**Age Band:** 6–8  
**Domains:** Create / Discover / Build / Think / Connect / Lead / Move / Express  
**Candidate Count:** 48  
**Scored Release Count:** Not yet determined

---

## 1. Candidate Item Standard

Each item is designed to measure:

> What would this child enjoy trying?

Not:

> What can this child already do well?

Candidate items must be reviewed for:

- construct clarity
- age appropriateness
- reading load
- cultural dependency
- resource dependency
- social desirability
- accessibility
- bilingual equivalence
- visual neutrality

No candidate item below is approved for production merely because it appears in this document.
