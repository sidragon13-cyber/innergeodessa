**Status:** Style Exploration Review  
**Scope:** Pre-Pilot Visual References  
**Production Assets Reviewed:** 0  
**Production Artwork Approved:** No

---

## 1. Purpose

This review records the two visual-generation experiments created before formal independent Pilot Asset production.

These images are classified as:

- **Style Exploration Reference A**
- **Style Exploration Reference B**

They are not assessment assets.

They must not be used directly in the production assessment.

The purpose of these references is to identify:

- suitable visual direction;
- style problems;
- construct-representation risks;
- ability-contamination risks;
- accessibility strengths and weaknesses;
- cross-image attractiveness imbalance.

---

## Format

Three-item composite reference sheet containing:

The reference also contained:

## 3. Reference A — Strengths

### CREATE-01

The scene successfully communicated:

- creative participation;
- use of shapes and drawing;
- child engagement;
- original visual activity.

The concept was understandable.

### THINK-02

The scene successfully communicated:

- sequencing;
- arranging items;
- structured activity.

### MOVE-02

The scene successfully communicated:

- movement;
- multiple participants;
- wheelchair participation;
- different movement methods;
- equal involvement.

MOVE-02 provided useful evidence that accessibility can be represented naturally rather than as a separate special-needs scene.

---

## 4. Reference A — Problems

### Problem 1 — Wrong Asset Format

The image was generated as one combined reference sheet.

Formal assessment assets require:

- one item per asset;
- independent asset version;
- independent review;
- independent file identity.

Therefore the composite format cannot become a production assessment asset.

---

### Problem 2 — Text Inside Visual Asset

The reference contained:

- item IDs;
- titles;
- footer text.

The Illustration Production Standard specifies that scored assessment illustrations should contain no embedded instructional or identifying text by default.

Therefore Reference A fails production-format requirements.

---

### Problem 3 — Style Too Close to Commercial / Rendered Imagery

The visual style was relatively polished, dimensional, and visually rich.

Potential risks:

- excessive attractiveness;
- advertising-like visual quality;
- unnecessary realism;
- higher emotional engagement than required for assessment comprehension.

The desired direction is more controlled:

**clean editorial illustration**

rather than:

**commercial children's promotional artwork**.

---

### Problem 4 — CREATE Attractiveness Bias

CREATE-01 contained:

- many colourful materials;
- finished artwork;
- visually rich background elements.

This made the Create scene naturally more colourful and potentially more attractive than the Think scene.

The assessment must not make Create appear preferable because of colour richness.

---

### Problem 5 — THINK Ability Contamination

The THINK-02 sequence visually resembled a task the viewer could solve.

This creates risk that the child interprets the image as:

> What comes next?

instead of:

> Would I enjoy arranging sequences like this?

This is a critical distinction.

The assessment measures interest.

It must not silently become an ability test.

---

# 5. Style Exploration Reference B

## Format

Second three-panel visual exploration containing the same three pilot constructs:

- CREATE-01
- THINK-02
- MOVE-02

The style moved closer toward a softer illustration system.

However, the output remained a combined triptych rather than three independent assessment assets.

---

## 6. Reference B — Improvements

Compared with Reference A:

- visual styling became more illustration-like;
- scenes became softer;
- visual hierarchy became simpler;
- the three concepts became more stylistically consistent;
- embedded item-title presentation was reduced;
- accessibility representation remained visible.

This was directionally better.

---

## 7. Reference B — Remaining Problems

### Problem 1 — Still a Composite Asset

The output remained a three-panel image.

Therefore it still cannot support:

- independent asset versioning;
- independent frontend use;
- independent item review;
- independent regeneration.

---

### Problem 2 — THINK Still Too Close to a Sequencing Task

The butterfly/lifecycle sequence strongly communicates a known chronological sequence.

This creates two risks:

1. previous knowledge may influence the child's reaction;
2. the child may attempt to solve or evaluate the sequence instead of evaluating interest.

The final THINK-02 illustration should show:

> a child participating in a sequencing activity

without requiring the viewer to identify the sequence rule.

---

### Problem 3 — MOVE Still Resembles an Activity Course

MOVE-02 successfully represented different movement methods.

However, the scene still contains some visual features associated with:

- obstacle courses;
- sport;
- physical performance;
- activity competition.

The next version should feel more like:

**exploration stations**

and less like:

**physical challenge course**.

---

### Problem 4 — Cross-Image Attractiveness Remains Uneven

CREATE and MOVE contain more:

- colour;
- objects;
- environmental detail;
- visual action.

THINK remains comparatively quieter.

The final asset set requires more consistent:

- colour intensity;
- object count;
- character scale;
- visual energy;
- background complexity.

# 9. Master Visual Direction — Preliminary Decision

The next generation should move toward:

- clean editorial illustration;
- clearly illustrated rather than photographic/rendered;
- simple shapes;
- controlled detail;
- soft but not highly decorative colour;
- one clear primary action;
- low background complexity;
- mild neutral-positive expression;
- ordinary materials;
- internationally understandable environment;
- no embedded text;
- no advertising composition;
- no cinematic visual effects.

---

# 10. Pilot Asset Format Requirement

The formal Pilot Asset stage must generate three independent images:

1. `K68-CREATE-01`
2. `K68-THINK-02`
3. `K68-MOVE-02`

Each image must be:

- independent;
- 4:3 landscape;
- no text;
- no title;
- no footer;
- individually versioned;
- individually reviewable.

The images should not be generated as a triptych, reference sheet, comparison board, or collage.

---

# 11. K68-CREATE-01 Direction

The independent asset should show:

- one child;
- shaping an original visual idea;
- multiple simple creative methods available;
- ordinary materials;
- low-resource environment;
- creative process rather than finished artistic quality.

Avoid:

- polished artwork;
- excessive colours;
- professional art tools;
- praise/reward cues;
- conventional drawing as the only method.

---

# 12. K68-THINK-02 Direction

The independent asset should show:

- one child;
- arranging a simple sequence;
- activity visibly in progress;
- no missing-answer slot;
- no puzzle directed at the viewer;
- no right/wrong cues.

The viewer must understand:

> the child is doing a sequencing activity

without needing to solve it.

---

# 13. K68-MOVE-02 Direction

The independent asset should show:

- children exploring several simple stations;
- multiple valid movement methods;
- equal participation;
- ordinary environment;
- no race;
- no competition;
- no winner;
- no speed emphasis.

The scene should communicate:

**movement-based exploration**

rather than:

**sports performance**.
