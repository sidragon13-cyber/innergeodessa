# InnerGeo Kids — Illustration Production Standard V1.0

**Status:** Production Preparation Standard  
**Scope:** Kids Assessment Illustration Generation  
**Applies To:** Ages 6–8 Required illustrations first, future Kids assets later  
**Production Artwork Approved:** No

---

## 1. Purpose

This standard defines how InnerGeo Kids assessment illustrations must be produced so that visual consistency does not become a source of measurement bias.

The objective is not:

> Create the most beautiful children's illustrations.

The objective is:

> Create clear, consistent, age-appropriate illustrations that help children understand an activity without changing what the assessment measures.

---

## 2. Production Principle

Every assessment image must satisfy:

Construct Match
+
Age Comprehension
+
Visual Consistency
+
Bias Control
+
Accessibility
+
Version Traceability

An image that fails any one of these areas is not production ready.

---

## 3. Master Visual Style

Use one controlled illustration system across the assessment.

Recommended direction:

- clean editorial illustration
- simple geometric forms
- soft dimensionality
- friendly but not cartoon-exaggerated
- minimal visual clutter
- clear activity focus
- neutral-positive emotional tone
- modern and internationally understandable
- no commercial visual language
- no collectible-game aesthetics

The same master style must apply across all domains.

---

## 4. Canvas Standard

Recommended master canvas:

**4:3 landscape**

Reason:

- enough horizontal space for activity context;
- compatible with desktop and mobile cards;
- easier to maintain consistent subject scale;
- supports one or two characters without excessive empty space.

Suggested production master:

**1600 × 1200 px**

Web delivery versions may later be generated from the master.

Do not independently redesign compositions for different device sizes during the assessment phase.

---

## 5. Safe Composition Area

Primary activity should remain within the central safe region.

Avoid placing essential meaning:

- at extreme edges;
- in corners;
- behind UI overlays;
- in small background details.

The activity should remain understandable if the image is moderately cropped.

---

## 6. Primary Subject Scale

Maintain comparable subject size across images.

Recommended:

- primary character/object occupies approximately 35–55% of the visual area;
- avoid one image using an extreme close-up while another uses a distant scene;
- avoid heroic low-angle compositions;
- avoid dramatic wide-angle perspectives.

Visual importance should come from clarity, not scale dominance.

---

## 7. Character Count

Default:

- 1 character for individual activity;
- 2 characters when interaction is necessary;
- small group only where the construct requires group activity.

Do not add extra children merely to make the image lively.

More characters create:

- visual complexity;
- social-status cues;
- popularity cues;
- gender/cultural balancing problems.

---

## 8. Character Age

Characters should visually appear approximately within the target child range.

For Ages 6–8 assets:

- child-like proportions;
- no teenage styling;
- no adult-like fashion;
- no infantilised toddler proportions.

Children should be able to recognise:

> Someone roughly like me doing this activity.

---

## 9. Character Expression

Default emotional tone:

**engaged / attentive / mildly positive**

Avoid:

- exaggerated excitement;
- boredom;
- frustration;
- fear;
- pride poses;
- victory expressions;
- applause;
- admiration.

Facial emotion must not tell the child which activity is more enjoyable.

---

## 10. Character Pose

Use natural activity-oriented poses.

Avoid:

- superhero stance;
- authority stance;
- dramatic pointing;
- winner pose;
- submissive follower pose;
- exaggerated performance gesture.

The pose should communicate the activity, not social status.

---

## 11. Representation Across the Set

The full asset set should include diversity in:

- skin tone;
- hair texture;
- gender presentation;
- clothing;
- physical participation.

Representation should be distributed across the bank.

Do not encode domain stereotypes such as:

- boys = Build;
- girls = Create;
- boys = Think;
- girls = Connect.

No domain should acquire a demographic identity.

---

## 12. Clothing Standard

Use:

- simple everyday clothing;
- neutral casual styles;
- no visible logos;
- no luxury cues;
- no school-uniform dependency unless construct requires school context.

Avoid clothing that strongly signals:

- wealth;
- nationality;
- profession;
- elite education;
- religion.

---

## 13. Environment Standard

Use minimal environments that clarify the activity.

Possible:

- simple indoor table;
- neutral activity space;
- basic classroom-like environment without school branding;
- ordinary outdoor path;
- simple natural setting.

Background exists to explain context.

It should not become another source of attraction.

---

## 14. Background Complexity

Use low-to-medium complexity.

Recommended:

- one clear primary activity;
- two to five supporting objects;
- minimal decorative detail.

Avoid:

- busy shelves;
- posters;
- complex city scenes;
- crowds;
- highly detailed landscapes;
- decorative clutter.

---

## 15. Colour Intensity

Use comparable overall colour intensity across all images.

No domain-specific visual privilege.

Avoid:

- Create = rainbow;
- Discover = glowing blue science;
- Think = futuristic neon;
- Move = highly saturated green landscape;
- Lead = powerful red;
- Connect = sentimental warm glow.

Domain meaning must come from action.

---

## 16. Palette Consistency

Use one shared base palette system.

Individual images may vary naturally, but should remain within comparable:

- saturation;
- brightness;
- contrast;
- warmth.

No single image should visually “pop” much more strongly than the others.

---

## 17. Lighting

Use:

- soft even lighting;
- minimal dramatic shadow;
- natural visual hierarchy.

Avoid:

- spotlight;
- cinematic rim light;
- glowing objects;
- magical effects;
- heroic lighting.

Assessment artwork is not advertising artwork.

---

## 18. Object Novelty

Novel objects can strongly attract children.

Therefore avoid unnecessary:

- robots;
- drones;
- tablets;
- gaming devices;
- advanced machines;
- exotic animals;
- rare equipment.

If technology is required by a future item, novelty must be controlled across comparison items.

---

## 19. Brand and IP Control

No visible:

- logos;
- trademarks;
- copyrighted characters;
- game brands;
- toy brands;
- sports brands;
- software branding.

Generic equivalents only.

---

## 20. Resource Neutrality

Prefer materials accessible across different socioeconomic backgrounds.

Examples:

- paper;
- cardboard;
- shapes;
- blocks;
- sticks;
- ordinary containers;
- generic objects;
- basic natural materials.

Avoid making opportunity exposure appear equal to interest.

---

## 21. Ability Boundary

Images must illustrate:

> participating in an activity.

They must not require:

> successfully completing the activity.

Especially for:

- Think;
- Discover;
- Build.

Do not present:

- unsolved IQ puzzles;
- hidden-object tests;
- graded tasks;
- correct-answer choices;
- skill performance comparisons.

---

## 22. Accessibility Production Rule

Each illustration should be checked for unnecessary dependence on:

- conventional walking;
- running;
- fine hand dexterity;
- speech;
- hearing;
- visual acuity;
- reading.

Where construct allows, depict multiple valid ways of participating.

Accessibility should appear normal, not exceptional.

---

## 23. Text Inside Images

Default:

**No text inside scored illustrations.**

Avoid:

- labels;
- speech bubbles;
- written instructions;
- numbers that require reading;
- signs;
- answer choices.

Assessment wording remains outside the image.

Exceptions require explicit review.

---

## 24. Symbols and Icons

Use only universally understandable visual symbols.

Avoid:

- culturally specific academic symbols;
- unexplained icons;
- achievement stars;
- badges;
- trophies;
- check marks;
- crosses implying wrong answers.

---

## 25. Image Generation Prompt Architecture

Every generated image prompt should internally contain the following layers:

### Layer A — Master Style

Defines the shared InnerGeo Kids visual system.

### Layer B — Scene

Defines the activity required by the item.

### Layer C — Composition

Defines character count, camera distance, subject scale, and background complexity.

### Layer D — Bias Controls

Defines prohibited stereotypes, wealth cues, emotional cues, and visual rewards.

### Layer E — Accessibility Controls

Defines alternative participation where relevant.

### Layer F — Negative Constraints

Defines elements that must not appear.

The prompt should not be improvised from scratch for every item.

---

## 26. Master Prompt Structure

Internal prompt template:

> InnerGeo Kids assessment illustration, consistent clean editorial illustration style, 4:3 landscape composition, child aged approximately 6–8 engaged in [ACTIVITY], clear primary action, simple everyday environment, moderate subject scale, minimal background detail, soft even lighting, balanced colour intensity, neutral-positive expression, age-appropriate proportions, internationally understandable scene, ordinary low-resource materials where possible, no visible brands, no text, no trophies, no dramatic emotional cues, no luxury cues, no stereotyped gender association, no cinematic lighting, no game-like reward effects.

Then append item-specific requirements.

---

## 27. Negative Prompt Standard

Where supported, prohibit:

- text;
- logos;
- watermark;
- trophy;
- medal;
- stars;
- applause;
- celebrity;
- luxury setting;
- dramatic lighting;
- superhero pose;
- competition;
- brand characters;
- commercial toys;
- school grades;
- test score;
- right/wrong indicators;
- excessive facial emotion;
- photorealistic advertising style.

---

## 28. File Naming

Recommended format:

`kids-k68-[domain]-[item-number]-v[asset-version].webp`

Example:

`kids-k68-think-01-v1.webp`

Source/master files may use PNG before optimisation.

---

## 29. Asset Versioning

Each image must have an asset version independent from question wording version.

Example:

- Item content: V1.0
- Illustration asset: V1
- Revised illustration: V2

Do not overwrite reviewed assets without increasing asset version.

---

## 30. Asset Metadata

For each generated asset record:

- item ID;
- domain;
- age band;
- content version;
- image version;
- generation date;
- master prompt version;
- item-specific prompt;
- production model/tool if relevant internally;
- reviewer;
- construct-match status;
- bias-review status;
- accessibility-review status;
- approval status.

---

Recommended future structure:

```text
public/
  assessments/
    kids/
      age-6-8/
        create/
        discover/
        build/
        think/
        move/Only approved web-delivery assets belong in the public production path.

Draft generations should remain outside the production asset directory until approved.

32. Production Status Model

Each visual asset should move through:

Generated

Image exists.

Content Matched

Scene correctly represents intended construct.

Visual Balanced

Attractiveness is comparable with the wider set.

Bias Reviewed

Gender, cultural, socioeconomic, status, and social desirability risks reviewed.

Accessibility Reviewed

Relevant accessibility risks reviewed.

Pilot Approved

Suitable for candidate/pilot assessment.

Production Approved

Approved after required evidence and release process.

Generated does not mean approved.

33. Batch Review Rule

Do not approve images only one at a time.

After individual review, display the entire Required set together.

Review for:

inconsistent saturation;
inconsistent visual detail;
one unusually attractive image;
repetitive demographic assignment;
domain colour coding;
inconsistent character age;
inconsistent art style.

Cross-image bias may be invisible when viewing one image alone.

34. Regeneration Rule

Regenerate an image if:

construct is unclear;
visual energy is too high;
activity is mistaken for another domain;
resource cues are excessive;
accessibility is poor;
character emotion is too strong;
style drifts from the master set;
image contains artefacts;
one asset becomes disproportionately attractive.

Do not keep a weak image merely because generation took time.

35. Image Editing Rule

When only a limited visual defect exists, controlled editing may be preferable to full regeneration.

Examples:

remove brand-like mark;
simplify background;
adjust inappropriate object;
reduce emotional expression;
correct accessibility representation.

Any material edit creates a new asset version.

36. Pilot Asset Principle

The first generated 14-image set should be treated as:

Pilot Visual Asset Set

Not final production artwork.

The objective of the first batch is to test:

style consistency;
construct readability;
attractiveness balance;
illustration bias;
practical frontend integration.
37. Commercial Release Boundary

No Kids illustration should be described as professionally validated merely because:

it follows this standard;
it passed visual review;
it looks consistent;
it was generated using AI.

Professional and empirical validation remain separate processes.

38. Production Principle

Consistency is part of measurement quality.

A visually beautiful but inconsistent set can reduce assessment quality.

For InnerGeo Kids:

clarity is more important than spectacle.

comparability is more important than novelty.

measurement quality is more important than decoration.
