# 02｜Thinking & Decision Structure

## Information Processing: Move from Experience Details to Repeating Patterns

A Sensing preference may make it easy to remember:

- one interaction;

- one live change;
- one user reaction.

The Profile B task is:

2. Who experiences it most often?
