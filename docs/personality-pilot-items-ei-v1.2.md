EI directional scoring:

- E-keyed item: `E contribution = raw value`; `I contribution = 6 - raw value`.
- I-keyed item: `I contribution = raw value`; `E contribution = 6 - raw value`.
- Equivalent signed score: E-keyed items use `raw - 3`; I-keyed items use `3 - raw`.
- Positive signed totals indicate an E tendency; negative totals indicate an I tendency; values near zero indicate balanced or weak differentiation.

## 8. Post-pilot analysis specification

Run analysis at item, subdimension and full EI levels.

| Analysis | Review purpose | Initial flag criterion |
| --- | --- | --- |
| Missing response rate | Accessibility or wording problem | `>5%` |
| Category distribution | Unused or overused response options | Any category `<5%`, interpreted with sample size |
| Extreme endorsement | Floor or ceiling concentration | Responses 1+2 or 4+5 `>80%` |
| Corrected item–total correlation | EI discrimination | `<0.20` serious review; `0.20–0.29` caution |
| Within-subdimension correlation | Local construct consistency | Negative or near-zero correlation |
| Inter-item correlation | Redundancy | `>0.70` review for duplication |
| Alpha or omega if item deleted | Reliability contribution | Remove only with construct evidence, not mechanically |
| E/I known-pattern comparison | Directional validity | Item moves opposite to coherent pattern |
| Differential item functioning | Language, region or demographic bias | Material effect after matching on trait level |
| Cognitive feedback | Misinterpretation or ambiguity | Repeated common misreading |
| Response time | Reading or comprehension burden | Repeated extreme delays relative to form median |

Reliability coefficients must not be the sole deletion rule. Retention decisions must combine statistical evidence, construct coverage, bias review and wording evidence.
