# InnerGeodessa Personality Assessment Pilot V1.0

## Structure

- EI: 18 items
- SN: 18 items
- TF: 18 items
- JP: 18 items

Total: **72 items**

### Administration

- Five-point Likert scale
- Randomized presentation
- One item per screen (recommended)
- Record response time for every item
- Save progress automatically

### Randomization constraints

1. Do not present two consecutive items from the same dimension.
2. Do not present two consecutive items from the same subdimension.
3. Alternate keyed direction where practical.
4. Separate scenario items when possible.
5. Preserve balanced coverage of all four dimensions.

### Questionnaire Flow

Consent
→ Demographics
→ 72 Personality Items
→ Cognitive Feedback
→ Completion
