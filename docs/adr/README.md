# Architecture Decision Records

ADRs record durable decisions that constrain future implementation. They
explain why a decision exists; engineering standards explain how to apply it.

## Format

Each ADR contains:

- status;
- context;
- decision;
- consequences.

Use sequential filenames. Accepted decisions are not rewritten to hide later
changes. Supersede them with a new ADR and link both records.
