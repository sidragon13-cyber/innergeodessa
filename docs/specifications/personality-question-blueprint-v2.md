# InnerGeo Personality Question Blueprint V2

**Status:** Draft for implementation

**Question bank target:** `personality-v2.0.0`

## Fixed rules

- 72 questions total.
- 18 questions per dimension.
- Nine questions per pole.
- Existing IDs and orders remain stable.
- One construct per question.
- No ability, intelligence, morality or mental-health claims.
- Both poles must remain reasonable.
- Questions measure ordinary preference, not competence.
- English and Chinese must measure the same construct.
- The production bank remains a five-point agreement scale in V2.

# Dimension coverage requirements

## EI

Must distinguish external versus internal processing and energy orientation.
It must not measure confidence, popularity, social skill, shyness or loneliness.

## SN

Must distinguish concrete information processing from abstract pattern processing.
It must not frame S as intelligent realism or N as imagination without evidence.

## TF

Must distinguish decision criteria.
It must not frame T as cold or F as kind, moral or emotionally unstable.

## JP

Must distinguish closure and structure from openness and adaptation.
It must not frame J as responsible or P as careless.

# Implementation sequence

1. Write all 72 English prompts.
2. Review construct duplication.
3. Write all 72 Chinese prompts.
4. Review bilingual equivalence.
5. Replace prompts in `questions.ts`.
6. Set all question metadata to content version `2.0.0`.
7. Set status to `review` until validation completes.
8. Change the synchronized bank version to `personality-v2.0.0`.
9. Generate backend `items.json`.
10. Preserve `personality-v1.0.0` database records for historical sessions.
11. Run question, sync, scoring, frontend and backend regression validation.
