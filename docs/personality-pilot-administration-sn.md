# InnerGeodessa SN Pilot Administration Guide

| Field | Value |
| --- | --- |
| Assessment | Personality V1.0 |
| Dimension | Sensing–Intuition |
| Pilot form | personality-pilot-items-sn-v1.2.md |
| Items | 18 |
| Scale | 5-point agreement |
| Status | Ready for pilot |

## 1. Objective

Evaluate wording quality, construct clarity, accessibility, duplicate risk and preliminary psychometric performance of the 18-item SN pilot form.

This pilot is **not** intended to classify participants or provide production personality reports.

## 2. Target sample

- Minimum pilot: 200 respondents
- Preferred: 400–600 respondents
- Multiple age groups
- Multiple education levels
- Multiple first languages
- Multiple countries or regions where possible

## 3. Administration rules

- Complete individually.
- No discussion during completion.
- No right or wrong answers.
- Respond according to usual preference rather than current mood.
- One response per item.
- Completion target: 4–8 minutes.

## 4. Response scale

| Response | Value |
| --- | ---: |
| Strongly disagree | 1 |
| Disagree | 2 |
| Neither agree nor disagree | 3 |
| Agree | 4 |
| Strongly agree | 5 |

## 5. Data quality rules

Flag responses for review when:

- completion time is unusually short;
- identical response chosen for every item;
- excessive missing responses;
- contradictory participant feedback;
- duplicate submissions.

Exclude only after documented review.

## 6. Cognitive feedback

After completion ask:

1. Which item was hardest to understand?
2. Which two items felt similar?
3. Did any wording feel culturally unusual?
4. Any word or phrase unclear?

## 7. Data to record

- anonymous respondent ID
- age band
- country/region
- first language
- assessment language
- start time
- submit time
- completion seconds
- raw responses
- optional comments
- consent status

## 8. Success criteria

- Missing responses below 5%.
- Average completion under 8 minutes.
- No item repeatedly misunderstood.
- No evidence of systematic language bias.
- Candidate set suitable for psychometric analysis.

## 9. Next step

After pilot completion:

1. Import response CSV.
2. Run item analysis.
3. Review discrimination and reliability.
4. Replace weak items if necessary.
5. Lock SN Production Version.
